# Post-click конверсии в Google Таблицах

Скрипт Google Apps Script забирает конверсии через **Reporting API** Яндекс.Метрики (как конструктор отчётов: группировка по времени визита и метрики «целевые визиты») и пишет на **первый лист** строки:

- **П.П.** — порядковый номер
- **Тип конверсии** — `Прямая` или `Ассоциированная`
- **Дата/время** — `YYYY-MM-DD HH:mm:ss`
- **Цель в ЯМ** — имя цели

Ввод (счётчик, период, OAuth-токен, метка, цели) — только в боковом HTML-меню, не в ячейках. Токен хранится в свойствах документа.

## Как считаются типы

Сегменты как в интерфейсе Метрики (атрибуция «последний значимый переход», кросс-девайс):

- **Прямая** — визит, в выбранном поле (`utm_source` по умолчанию) есть метка; `utm_medium` не `test`.
- **Ассоциированная** — у человека метка была одним из источников за период (`USER`), а в текущем визите метки уже нет. Без метки этот тип не считается.
- Пустая метка — выбранные цели по **всем источникам**, тип у всех строк `Прямая`.

Роботы отфильтрованы (`isRobot = No`). Время в таблице — дата и время **визита**, как в группировке кабинета.

## Установка

1. Откройте Google-таблицу → **Расширения** → **Apps Script**.
2. Удалите содержимое стандартного `Code.gs` и создайте файлы из папки [`apps-script`](apps-script):
   - `Code.gs`
   - `MetrikaLogs.gs`
   - `MetrikaReports.gs`
   - `Classify.gs`
   - `PostView.gs`
   - `Sheets.gs`
   - `PostView.gs`
   - `Sidebar.html`
   - `InterestsSidebar.html`
   - `SearchLift.gs`
   - `SearchLiftSidebar.html`
   - `appsscript.json`
3. Сохраните проект (`Ctrl+S`) и обновите таблицу — появится меню **Автоматизация**.
4. **Автоматизация → Конверсии → Post-click из Метрики** — конверсии.
5. **Автоматизация → Аудитория → Интересы из Метрики** — интересы и аффинити-индекс.
6. **Автоматизация → Search Lift → Открыть панель** — Wordstat / Search Lift (серо-чёрная панель).
7. Для конверсий: заполните форму, нажмите **Загрузить цели**, отметьте нужные, затем **Выгрузить конверсии**.
8. Для интересов: счётчик, период, метка (можно пустую), поле метки и уровень (1 / 2 / 3), затем **Выгрузить интересы**.

Post-click и интересы пишут на **первый лист** и заменяют его содержимое. Запускайте нужный отчёт отдельно.

Новые пункты позже добавляйте в `onOpen()` в `Code.gs` (`addItem` / `addSubMenu`).

## Post-view CPM (лист таблицы)

Скрипт не ходит в API: обрабатывает **активный лист** с уже вставленным сырым отчётом (например `post_view_report_CPM`).

1. Импортируйте xlsx в Google Таблицу или вставьте отчёт на лист.
2. Встаньте на этот лист (не на лист результата).
3. **Автоматизация → Конверсии → Post-view таблица**.

Что происходит:

- шапка обычно на 6-й строке: **ID Конверсии**, **Тип конверсии**, даты, **ID Кампании** … **Programmatic ID**, **clientID YM**;
- на исходнике удаляются колонки от **ID Кампании** до **Programmatic ID** (включительно);
- если в «типе конверсии» нет значений post-view (в CPM-отчёте там цели вроде «E-commerce: покупка»), строки не отбрасываются — весь файл уже post-view;
- дубли по **clientID YM** снимаются: остаётся строка с самой поздней датой конверсии;
- на лист **Post-view** пишется таблица **с шапкой**, строки сгруппированы по типу конверсии;
- справа — сколько было PV по каждой цели (до снятия дублей).

Если блок ID компании…programmatic ID уже вырезан, повторный запуск только пересобирает лист результата.

## Интересы аудитории

Reporting API, шаблон «Долгосрочные интересы»:

- группировка `ym:s:interest2d1` … `interest2d3` по выбранному уровню;
- метрики: посетители (`ym:s:users`) и аффинити-индекс (`ym:s:affinityIndexInterests2`);
- фильтр по метке — тот же, что у post-click (подстрока в выбранном UTM-поле / `lastTrafficSource`, атрибуция последнего значимого перехода);
- пустая метка — интересы по **всем источникам**.

На листе сверху — параметры запуска; с 7-й строки — таблица интересов. Если Метрика семплировала отчёт, об этом будет написано в шапке и в сайдбаре.

## OAuth-токен Метрики

Нужно право `metrika:read`.

1. Создайте приложение на [oauth.yandex.ru](https://oauth.yandex.ru) с доступом «Получение статистики, чтение параметров своих и доверенных счётчиков».
2. Откройте:

   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ИД_ПРИЛОЖЕНИЯ`

3. Скопируйте `token` из адресной строки и вставьте в боковое меню.

Не коммитьте токен в git.
